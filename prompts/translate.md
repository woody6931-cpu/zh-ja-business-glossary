# AI 商务翻译提示词

可以直接粘贴到 ChatGPT、Claude 等 AI 里使用。

---

## 中文 → 日语商务邮件

```
请把下面的中文翻译成日语商务邮件。

要求：
- 对象是【客户 / 供应商 / 公司内部】，使用相应的敬语等级
- 对外邮件用「お世話になっております」开头，用「よろしくお願いいたします」结尾
- 称对方公司用「貴社」，称自己公司用「弊社」
- 专业术语按以下对照翻译：【粘贴 terms.csv 中相关的几行】
- 不要逐字直译，要写成日本人自然的商务表达
- 最后用中文简单说明你在敬语或表达上做了哪些调整

原文：
【粘贴中文】
```

## 日语 → 中文（理解对方真实意思）

```
请把下面这封日语商务邮件翻译成中文。

除了翻译，请再告诉我：
1. 对方的真实意图是什么（日本商务邮件经常很委婉，比如「検討いたします」可能是婉拒）
2. 邮件里有没有需要我回复或处理的事项、期限
3. 对方的语气是正常、不满，还是着急

原文：
【粘贴日文】
```

## 检查自己写的日语

```
下面是我写的日语商务邮件，请帮我检查：
1. 敬语有没有用错（尊敬语、谦让语混用等）
2. 有没有不自然、日本人不会这样说的地方
3. 有没有可能让对方误解或觉得失礼的表达

请给出修改后的完整版本，并用中文逐条说明改了什么、为什么改。

邮件：
【粘贴日文】
```

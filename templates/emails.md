# 日语商务邮件模板（中日对照）

用法：把【】里的内容换成实际信息。日文是可以直接发送的版本，中文是意思说明，不是逐字翻译。

---

## 1. 询价（初次联系供应商）

**件名：** 【商品名】のお見積りのお願い

```
【会社名】
【部署名】【担当者名】様

突然のご連絡失礼いたします。
合同会社【自社名】の【氏名】と申します。

貴社ウェブサイトにて【商品名】を拝見し、
お取引をご検討させていただきたくご連絡いたしました。

つきましては、下記条件にてお見積りをいただけますでしょうか。

・商品名：【商品名・型番】
・数量：【数量】
・納品先：【住所】
・希望納期：【日付】

お忙しいところ恐れ入りますが、
ご検討のほどよろしくお願いいたします。
```

**中文意思：** 初次冒昧联系。在贵公司网站看到某商品，想洽谈合作，请按以下条件报价。

---

## 2. 发送报价单

**件名：** お見積書送付のご案内

```
【会社名】
【担当者名】様

いつもお世話になっております。
合同会社【自社名】の【氏名】です。

先日ご依頼いただきました【商品名】のお見積書を
添付にてお送りいたします。
ご査収のほど、よろしくお願いいたします。

なお、本お見積りの有効期限は【日付】までとなっております。
ご不明な点がございましたら、お気軽にお問い合わせください。
```

**中文意思：** 附上报价单请查收。报价有效期到某日，有疑问随时联系。

---

## 3. 下单 / 确认订单

**件名：** 【商品名】発注のご連絡

```
【会社名】
【担当者名】様

いつもお世話になっております。
合同会社【自社名】の【氏名】です。

【日付】付のお見積書（No.【番号】）の内容にて、
正式に発注させていただきます。
発注書を添付いたしますので、ご確認をお願いいたします。

お手数ですが、注文請書をご返送いただけますと幸いです。
```

**中文意思：** 按某日报价单正式下单，附订单，麻烦回传订单确认书。

---

## 4. 交期延误道歉

**件名：** 【商品名】納期遅延のお詫び

```
【会社名】
【担当者名】様

いつもお世話になっております。
合同会社【自社名】の【氏名】です。

【日付】納品予定の【商品名】につきまして、
【理由：例）輸入時の通関手続きに時間を要しており】、
納品が【新しい日付】頃となる見込みです。

ご迷惑をおかけし、誠に申し訳ございません。
今後このようなことがないよう、スケジュール管理を徹底いたします。

何卒ご理解いただけますよう、よろしくお願い申し上げます。
```

**中文意思：** 因某原因，原定某日的货预计推迟到某日，非常抱歉，今后会加强管理。

**要点：** 日本客户最在意的是"新的确切日期"，原因说清楚就好，不要过度解释。

---

## 5. 催款（委婉版）

**件名：** 【月】分ご請求についてのご確認

```
【会社名】
経理ご担当者様

いつもお世話になっております。
合同会社【自社名】の【氏名】です。

【日付】付でお送りいたしました請求書（No.【番号】）につきまして、
お支払期日の【日付】を過ぎておりますが、
現時点で入金の確認ができておりません。

行き違いでお支払いいただいている場合は、
ご容赦くださいますようお願いいたします。

お手数ですが、ご確認のほどよろしくお願いいたします。
```

**中文意思：** 某日的请款单已过付款期，目前还没确认到款。如果已经付了请忽略，麻烦确认一下。

**要点：** "行き違いの場合はご容赦ください"（如已支付请见谅）是日本催款邮件的标准写法，给对方留面子。

---

## 6. 婉拒

**件名：** 【件名】について

```
【会社名】
【担当者名】様

いつもお世話になっております。
合同会社【自社名】の【氏名】です。

この度は【内容】についてご提案いただき、誠にありがとうございました。
社内で検討いたしましたが、
誠に恐縮ながら、今回は見送らせていただくこととなりました。

せっかくご提案いただいたにもかかわらず、申し訳ございません。
今後とも何卒よろしくお願いいたします。
```

**中文意思：** 感谢提案，内部讨论后这次决定不采用，抱歉，今后仍请多关照。

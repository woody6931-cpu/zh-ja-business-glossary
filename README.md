# 中日商务用语词典 / 日中ビジネス用語集

在日本做贸易、或者和日本公司打交道时，通用翻译软件最容易翻错的，往往是行业术语和商务敬语。
这个仓库整理了实际业务中常用的中日对照术语、日语商务邮件模板和 AI 翻译提示词。

**在线查询：** 开启 GitHub Pages 后，访问 `https://<你的用户名>.github.io/zh-ja-business-glossary/`

## 内容

| 文件 | 说明 |
|---|---|
| [`glossary/terms.csv`](glossary/terms.csv) | 术语对照表：公司与职位、贸易与通关、物流、合同、报价订单、付款发票、商务用语 |
| [`templates/emails.md`](templates/emails.md) | 日语商务邮件模板：询价、报价、下单、延误道歉、催款、婉拒 |
| [`prompts/translate.md`](prompts/translate.md) | 用 AI 翻译商务邮件时的提示词 |
| `index.html` | 在线查询页面 |

## 使用方式

- **在线查：** 打开上面的网页，用中文、日文或假名读音搜索
- **导入翻译软件：** `terms.csv` 可以整理后导入支持自定义词表的翻译工具
- **配合 AI 用：** 把相关词条贴进 `prompts/translate.md` 里的提示词，让 AI 统一用词

## 特别容易出错的词

- **合同** ≠ 日语「合同」。中文的"合同"在日语里是「契約書」，日语的「合同」是"联合"的意思
- **インボイス** 在贸易里指商业发票，在税务里指 2023 年起的「適格請求書」，要看语境
- **検討いたします** 不一定代表对方会推进，有时是委婉的拒绝
- **社員** 在合同会社里指出资人，不是普通员工
